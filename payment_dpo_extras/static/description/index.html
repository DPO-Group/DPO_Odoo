DPO Pay Extras

More control over the DPO payment provider built into Odoo 19

Odoo 19 includes a DPO payment provider. DPO Pay Extras installs on top of it, so no files of Odoo are replaced and your existing DPO Service ID and Company Token keep working.

Features

  • Configurable Pay URL: use the DPO live or sandbox payment page. The API host follows it.
  • Service Description: send your own description to DPO instead of the order reference.
  • Block Bank Transfer and PayPal on the DPO payment page.
  • Payment Time Limit: control how long the DPO payment page stays valid.
  • Customer street address and phone are included in the payment request.
  • Clear errors: if DPO refuses to start a payment, the customer sees DPO's explanation.
  • Values are XML-escaped, so names such as "Smith & Sons" no longer break the request.

Setup

  1. Install DPO Pay Extras. Odoo's DPO provider is installed automatically.
  2. Go to Accounting or Website → Configuration → Payment Providers → DPO.
  3. Enter your Service ID and Company Token from DPO, choose Test Mode or Enabled and save.
  4. Adjust the extra options if needed.

Odoo 16, 17 and 18 use the full DPO Pay Payment Gateway module (payment_dpo). Odoo Online does not support third-party modules.
